# KeyPulse

An offline vault for configuration and secrets, by Theekshitha Labs.

**Website:** https://keypulse.dev · **Download page:** https://keypulse.dev/download

This repository holds the release files only. The source code is not published here.

## Which file to download

| You have | Download |
|---|---|
| Windows 10 or 11 | [Microsoft Store](https://apps.microsoft.com/detail/9P28TSCMB2WH) (updates itself and adds the `keypulse` command), or `KeyPulse-windows-x64.exe` |
| macOS (Apple silicon or Intel) | `KeyPulse-macos-universal.dmg` |
| Linux x64 | `KeyPulse-linux-x64.AppImage`, `.deb` or `.rpm` |
| The `keypulse` CLI on its own | `keypulse-cli-<platform>` |
| A team server for your office | `keypulse-server-<platform>` (see https://keypulse.dev/teams) |

The files are attached to each [release](https://github.com/theekshithalabs/keypulse/releases/latest).

The macOS app is not notarized yet: the first time, right-click KeyPulse and choose **Open**.
